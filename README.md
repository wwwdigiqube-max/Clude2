# استودیوی ویدیوی من (کیت NFP-Alvana، نسخه‌ی گوشی)

این ریپو استودیوی ساخت ویدیوی توست:
- Claude در کامپیوتر ابری با کد ویدیو می‌سازد: متن، صدا، انیمیشن و رندر.
- تو فقط از گوشی با او حرف می‌زنی.
- ویدیوهای تمام‌شده در پوشه‌ی [`videos/`](videos/) می‌آیند.

**راهنمای کامل قدم‌به‌قدم:** [`GUIDE-FA.md`](GUIDE-FA.md)

**ساخت یک ویدیو:**
1. اپ Claude را باز کن و برو به تب **Code**.
2. همین ریپو را انتخاب کن و یک جلسه‌ی تازه شروع کن.
3. بنویس چه ویدیویی می‌خواهی. نمونه:

> با سبک هولوگرام یه ریلز ۴۵ ثانیه‌ای درباره‌ی اینکه چرا آسمون آبیه بساز. اول متن رو نشونم بده.

**فرستادن فایل به Claude:**
- **عکس:** اول مستقیم در چت بفرست. اگر Claude گفت فایلش را ندارد، از راه پایین آپلود کن.
- **ویدیو، صدا، لوگو یا هر فایل تا ۲۵ مگ:**
  1. در پوشه‌ی [`uploads/`](uploads/) بزن Add file → Upload files.
  2. به Claude بگو «فایل‌ها رو توی uploads گذاشتم».

**کلیدها** (مثل ElevenLabs) را هرگز در چت ننویس. فقط در تنظیمات محیط ابری بگذار (راهنما، بخش ۲).
