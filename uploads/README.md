# uploads: فایل‌هایی که برای Claude می‌فرستی

**عکس** را اول مستقیم در چت بفرست. اگر Claude فایلش را داشت، آپلود لازم نیست. این پوشه برای ویدیو، صدا، لوگو، و عکسی است که Claude فایلش را نداشت.

**آپلود از گوشی:**
1. همین پوشه را در GitHub باز کن.
2. بزن **Add file → Upload files**.
3. فایل‌ها را انتخاب کن و بزن **Commit changes**.
4. به Claude بگو: «فایل‌ها رو توی uploads گذاشتم».

**چه چیزهایی اینجا بگذاری:**
- عکس‌هایی که با ChatGPT ساختی (اسم فایل همانی باشد که Claude گفته)
- لوگو (PNG با پس‌زمینه‌ی شفاف)
- ویس خودت
- ویدیوی مرجع

**نکته‌ها:**
- هر فایل حداکثر ۲۵ مگابایت (محدودیت آپلود از مرورگر).
- لازم نیست پوشه بسازی. همه را همین‌جا بگذار؛ Claude خودش مرتبشان می‌کند.
