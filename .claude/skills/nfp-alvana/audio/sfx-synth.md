# کتابخانه‌ی افکت صوتی مشترک
فایل‌ها: `public/sfx-lib/<name>.wav` · ساخت دوباره: `node tools/sfx-lib.mjs` · استفاده: `staticFile("sfx-lib/<name>.wav")` با `Html5Audio` داخل `<Sequence from layout="none">`.
**قانون:** هر صدا روی یک رویداد دیدنی؛ کوتاه و تونال؛ بدون نویز پیوسته (درس ویدیوی ۰۳). آخر کار `loudnorm`.

| نام | حس | کجا |
|---|---|---|
| thud | ضربه‌ی نرم بم | افتادن جسم، کات مهم |
| pin | تق چوبی | سنجاق، گذاشتن کارت |
| paper | خش‌خش کوتاه کاغذ | باز شدن یادداشت |
| steps | قدم‌های نرم | راه رفتن کاراکتر |
| boom | ساب‌بیس عمیق ۲ث | جمله‌ی پایانی، لحظه‌ی سنگین |
| pop | پاپ بالارونده | ظاهر شدن علامت/استیکر |
| blip | بیپ خیلی کوتاه | کات بلوپرینت، تشخیص |
| click | کلیک UI | دکمه |
| type | تایپ نرم ۱.۷ث | تایپ در نوار/ترمینال |
| ticks | تیک‌های تندشونده ۱.۹ث | شمارنده‌ی عدد |
| strike | ضربه‌ی نزولی کوتاه | خط‌خوردن |
| node1/2/3 | سه نت بالارونده | ظاهر شدن گره‌ها پشت‌سرهم |
| hop | پرش کوچک | پریدن کاراکتر |
| ping | زنگ کوتاه | هایلایت |
| match | دو نت شاد | پیدا شدن مورد |
| lock | دو نت قفل | قفل هدف |
| stop | زنگ دوتایی | توقف تایمر/پایان مرحله |
| chime | آکورد زنگ ۲ث | موفقیت نهایی |
| error | دو نت نزولی | اشتباه/رد |
| string | پلاک سیم | نخ/اتصال |
| sweep | گلیساندو تونال | کشیده شدن مسیر |
| whoosh | عبور نرم (فیلترشده) | ترنزیشن — کم استفاده شود |
| scan | اسکن تونال ۳.۷ث | موج اسکن نقشه |
| servo | موتور کوچک | چرخش دوربین/مکانیک |
| riser | بالارونده ۱.۵ث | قبل از عدد بزرگ |
| glitch | گلیچ دیجیتال | تغییر معنا، خطا |
| notif | دو نت نوتیفیکیشن | نوتیف گوشی |
| print | چاپگر سوزنی کوتاه | ردیف رسید |
| stamp | ضربه‌ی مهر | مهر روی کارت |

**بستر موزیک:** `node tools/music-bed.mjs spec.json out.wav` — پد + پلاک آرام؛ `arpFrom` (ثانیه‌ی شروع آرپ)، `busy` [از، تا] برای بخش پرانرژی، `stopAt` (قطع قبل از پایان)، `chords` (MIDI).
