# فهرست سبک‌ها
برای «با سبک X بساز»: فقط همین فهرست را بخوان، بعد کارت همان سبک (`styles/<id>.md`)، بعد از `src/styles/<id>/` ایمپورت کن.
**مرجع هر سبک = آخرین خروجی تأییدشده‌اش، به شکل کد.** کامپوزیشن `Style-<Name>` خودِ همان فیلم است و بی‌صدا رندر می‌شود. در نسخه‌ی گوشی Studio نداریم: کانتکت‌شیت را لینک بده، یا فریم‌های `-Look` را با `tools/deliver.mjs` بفرست. کیت ویدیوی رندرشده ندارد.
- کانتکت‌شیت هر سبک: `styles/previews/<id>.jpg`. قبل از ساخت ببینش تا سطح کیفیت دستت بیاید.
- برای دیدن لحظه‌های بیشتر: `npx remotion render Style-<Name>-Look out/look --sequence --image-format=jpeg --scale=0.5` و بعد یک کانتکت‌شیت از آن‌ها.
**سبک‌ها نقطه‌ی شروع‌اند، نه قفس.** می‌توانی دو سبک را ترکیب کنی، رنگ و چیدمان را عوض کنی، یا سبک کاملاً تازه بسازی (`SKILL.md`، بخش «آزادی»).

**انتخاب سریع:**
- **نریشن + عمودی:**
  - علم یا تکنولوژی ← Hologram HUD
  - تاریخ یا نوستالژی ← Atomic Age
  - نقشه و مکان ← Satellite Explainer
  - UI و لیست ← Receipt UI
  - کاراکتر ← Halftone Pop
  - انگلیسی ← Story Montage
- **نریشن تند + معرفی خود محصول یا استودیو (شوریل)** ← Test Reel
- **نریشن + معرفی دوره، پیج یا محصول با نمونه‌کار و آمار واقعی (اینستاگرام، یوتیوب، Claude)** ← Studio Desk
- **نریشن + افقی:**
  - داستان مشکل و راه‌حل ← Photocopy Story
  - توضیح فرایند ← Paper × Blueprint
  - بدون متن روی صفحه ← Pixel Collage
- **دو گوینده + افقی + بلند** (مستند، داستان، مفهوم) ← Documentary · فضا و کیهان ← Cosmic Web
- **دیالوگ کمدی کوتاه** ← Stick Toon
- **بدون نریشن:**
  - معرفی محصول روی موزیک ← Launch Reel
  - موزیک‌ویدیو یا اینترو ← Light Swarm
  - اینترو برند که **لوگوی خودت** را با نور می‌سازد ← Light Logo
  - شمارش معکوس، لانچ یا اعلام تاریخ ← Split-Flap Board
- **هیچ‌کدام نخورد؟** سبک تازه بساز (`REFERENCE.md`). موتورهای کیت را مثل آجر استفاده کن.

**فقط با گوشی (بدون کامپیوتر):** Claude Code در وب و اپ گوشی روی سرور ابری اجرا می‌شود که کارت گرافیک ندارد.
- ✅ **دوبعدی‌ها خوب درمی‌آیند:** Hologram HUD، Atomic Age، Test Reel، Studio Desk، Satellite Explainer، Stick Toon، Receipt UI، Photocopy Story، Paper × Blueprint، Halftone Pop، Story Montage، Pixel Collage، Launch Reel، Documentary. ویدیوی بلند را تکه‌ای رندر کن.
- 🐢 **سه‌بعدی‌ها در ابر کندند:** Light Swarm، Light Logo و Split-Flap Board روی CPU رندر می‌شوند (`--gl=swangle`، `--concurrency=2`). هر فریم ۴ تا ۸ ثانیه طول می‌کشد، یعنی اینترو ۱۵ ثانیه‌ای ۴۵ تا ۹۰ دقیقه.
- ❌ **Cosmic Web** فقط با کامپیوتر و کارت گرافیک.
- **نسخه‌ی گوشی کیت** (`NFP-Alvana-Mobile`) برای کار کامل از گوشی است: راه‌اندازی ابری، تحویل ویدیو با لینک یا تلگرام، و راهنمای PDF.
- فایلی که برای گوشی فرستاده می‌شود (Remote Control) حداکثر حدود ۳۰MB است. مستر 4K را روی کامپیوتر نگه دار و یک نسخه‌ی 1080p سبک برای گوشی بفرست.
- اگر کامپیوتر داری ولی می‌خواهی از گوشی کار کنی، Remote Control را بزن. کار روی همان کامپیوتر انجام می‌شود.

**ساختار سبک‌های جدیدتر** (hologram-hud، atomic-age، test-reel، stick-toon، satellite-explainer، cosmic-web، studio-desk، split-flap، light-logo):
- `src/styles/<id>/lib` (یا `rig`): موتور سبک. نخوانش؛ API در کارت است.
- `demo/`: **خود فیلم مرجع**، همان آخرین خروجی تأییدشده. برای ویدیوی تازه، این پوشه را به `src/vNN/` کپی کن و صحنه‌ها را عوض کن.
- `pipeline/`: فایل‌های واقعی ساخت همان فیلم: متن (`script.json` یا `lines.json`)، صدا (`voices.json`)، پرامپت عکس‌ها (`image-prompts.md`)، پرامپت افکت‌ها و موزیک (`sfx.json`، `music-plan.json`)، و برنامه‌ی میکس (`build-audio.mjs` یا `audio.json`). برای ویدیوی تازه کپی و ویرایششان کن.
- دارایی‌ها در `public/styles/<id>/` هستند: عکس‌ها و بافت‌ها، که در ویدیوی خودت هم می‌توانی استفاده کنی. صدای فیلم‌ها همراه نیست؛ دستور ساختش (متن، صدا، پرامپت افکت و موزیک، برنامه‌ی میکس) در `pipeline/` است.
- هر کارت یک «نقشه‌ی کد» دارد: کدام فایل چیست، چند توکن است، و کی باید بازش کنی.

**کتابخانه‌ی مشترک:** `src/lib/util.ts` (`ramp`، `fa`، `faNum`، `typed`، `rnd`، `timeline` و …) · `src/lib/geo/` (نقشه‌ی نقطه‌ای جهان) · `src/lib/audio-env/` (انرژی موزیک‌ها).

**وابستگی بین سبک‌ها** (تداخل ندارند، ولی این‌ها را جدا نکن):
- `hologram-hud`، `atomic-age` و `test-reel` زمان کلمه‌ها را با `makeCues` از `documentary/cues` می‌گیرند. `test-reel` ابرهای `public/styles/documentary/clouds` را هم استفاده می‌کند.
- `photocopy-story` دوربینش را از `story-montage/cam` می‌گیرد.
- `halftone-pop`، `stick-toon`، `satellite-explainer` و `cosmic-web` فونت‌ها را از `src/fonts.ts` می‌گیرند (`FONT_TEXT`، `FONT_NUM`).
- سبک‌های Canvas (`hologram-hud`، `atomic-age`، `test-reel`، `documentary`) فونت‌های خودشان را در `demo/Video.tsx` لود می‌کنند. همه‌ی فونت‌ها OFL هستند و در `public/fonts/` قرار دارند.
- `light-swarm`، `light-logo`، `split-flap` و `cosmic-web` سه‌بعدی‌اند (three.js + `@remotion/three` + postprocessing) و با `--gl=angle --concurrency=1` رندر می‌شوند. `cosmic-web` برای بارگذاری داده `--timeout=300000` هم لازم دارد.
- `light-logo` روی موتور `light-swarm` ساخته شده (شکل‌ها، math و timeline را از آن می‌گیرد). `studio-desk` لوگوی Claude را از `test-reel/lib/claude-logo` می‌گیرد.
- **لوگوی خودت:** `node tools/logo-trace.mjs logo.png <پوشه> [--accent=#hex] [--sub=x0,y0,x1,y1] [--cut=y] [--preview]` از PNG شفاف دو فایل می‌سازد:
  - `logo-paths.json` (مسیرهای برداری) برای ماژول پهن `split-flap`.
  - `logo-pts.json` (نقطه‌های نور) برای `light-logo`.
- هر سبک را از `index.ts` خودش ایمپورت کن. دو سبک را در یک فایل با `import *` قاطی نکن، چون اسم‌هایی مثل `P`، `Grain` و `caption` در چند سبک تکرار شده‌اند. اگر لازم شد، با اسم مستعار ایمپورت کن.
