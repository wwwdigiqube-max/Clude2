# Receipt UI (زیرنویس کلمه‌به‌کلمه + UI واقعی + رسید جریمه)
**وضعیت:** ✅ کد آماده در Remotion · `src/styles/receipt-ui/` · نمونه‌ی کامل (قالب شروع): `examples/v05/` · پیش‌نمایش: `styles/previews/receipt-ui.jpg`
**اسم‌های صدازدن:** «سبک رسید»، «سبک ویدیو ۵»، «زیرنویس کلمه‌ای با UI»
**مرجع:** ریلز انگلیسی «Your vibe-coded app can get sued» (رسید VIBE-CODED APP، UI‌های Stripe و فرم، سلکشن آبی) · **اولین استفاده:** ویدیوی ۰۵

## کی بزنیمش
ریلز عمودی **با نریشن**؛ لیست مشکلات/نکته‌ها که هرکدام یک UI واقعی دارد و «هزینه» روی یک رسید جمع می‌شود؛ آخرش راه‌حل + CTA کامنت.

## ظاهر در یک نگاه
- عمودی 1080×1920. صحنه‌ها یکی‌درمیان **روشن** (`#f2f2f3` + گرید) و **تیره** (`#0e0e10` + گرید)؛ ترنزیشن **اسمیر عمودی** (موشن‌بلر).
- بالا: **رسید** کاغذی که از لبه‌ی بالا آویزان است و با هر مشکل یک ردیف چاپ می‌کند (قرمز)؛ آخر کار ردیف‌ها خط می‌خورند و «✓ fixed» می‌شوند.
- وسط-بالا: **زیرنویس سینک با نریشن** (Vazirmatn 66): کلمه‌ی فعلی پررنگ، قبلی‌ها خاکستری، کلمه‌ی کلیدی در **کادر انتخاب آبی/قرمز با دستگیره** (مثل فیگما). کلمه‌های لاتین پشت‌سرهم LTR گروه می‌شوند.
- پایین: **قرص شمارش معکوس** «پرامپت · آخر ویدیو».
- وسط: UI واقعی (کارت سفید/تیره با سایه‌ی نرم)، برچسب قرمز **missing**، نشانگر موس با کلیک، گوشی.

## کد — شروع سریع
```tsx
import { Backdrop, Captions, Receipt, PromptPill, Smear, Card, … } from "../styles/receipt-ui";
```
1. نریشن: جمله‌ها را با توکن `tts|display` بنویس (مثل `tools/v05-narration.mjs`) ← `tts` بعد `words` ← `src/vNN/words.json`.
2. `times.ts`: همه‌ی رویدادها با `wordAt(WORDS, جمله, "کلمه")` (ثانیه) — هیچ عدد دستی.
3. `Video.tsx` را از v05 کپی کن: `SCENES` (کامپوننت + mode + from)، `ROWS` رسید، `KEYS` کلمه‌های کلیدی هر جمله، `CUES` صدا.
4. هر صحنه: `const { f, at } = useLocal(from)`؛ ظاهر شدن با `ramp(f, at(TM.x), at(TM.x)+9, easeBack)`.
چیدمان: رسید y 0–560 · زیرنویس y 620 · صحنه y 880–1700 · قرص y 1752.

## درس‌ها
- ⚠ **درس از ویدیوهای قبلی روی v1: «انیمیشن کمه، بیشتر تایپوگرافیه».** قانون این سبک: هر سکانس حداقل (۱) ورود سه‌بعدی/فلیپ، (۲) یک حرکت دائمی (شناوری، جریان ذرات، حلقه‌ی پالس، اسکرول کد)، (۳) یک ضربه روی کلمه‌ی کلیدی (Burst/Rings/لرزش/مهر)، (۴) یک المان تزئینی زنده (ایموجی، شمارنده، float-up). صحنه‌ی ایستا بعد از ظاهر شدن ممنوع.
- ✓ زمان‌بندی همه‌چیز از روی `alignment` الون‌لبز → سینک دقیق بدون دست‌کاری.
- ⚠ تیکه‌ی ۱–۲ کلمه‌ای آخر جمله تنها نماند (در `Captions` ادغام می‌شود).
- ⚠ برچسب لایه‌های ایزومتریک باید روی لبه‌ی جلویی (پایین) باشد، وگرنه زیر لایه‌ی بالایی گم می‌شود.
- ⚠ نشانگر موس روی متن دکمه نیفتد؛ نزدیک لبه‌ی راست دکمه.
- ⚠ `wordAt` اولین کلمه‌ای که *شامل* رشته است را می‌دهد («داری» ← «نداری»)؛ از `nth` استفاده کن.
