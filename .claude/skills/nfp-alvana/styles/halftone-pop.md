# Halftone Pop (کاراکتر سخنگوی هافتون + رنگ‌های پاپ)
**وضعیت:** 🟡 کد آماده در Remotion · `src/styles/halftone-pop/` · نمونه‌ی کامل: `examples/v08/` (کامپوزیشن `NFP-Promo`) · عکس‌های کاراکتر: `public/v08/char/` · پیش‌نمایش: `styles/previews/halftone-pop.jpg` · نسخه‌ی ۲ منتظر بازخورد
**اسم‌های صدازدن:** «سبک هافتون»، «کاراکتر سخنگو»، «سبک گامرود»، «سبک ویدیو ۸»
**مرجع:** پرومو Gumroad (سبک اصلی) + Pocketsflow عمودی (ژست‌ها) + ویدیوی خطی (جای متن) + افکت‌های pdoom-video · **اولین استفاده:** ویدیوی ۰۸ «NFP»

## کی بزنیمش
کاراکتری که حرف می‌زند و یک موضوع، داستان یا محصول را توضیح می‌دهد. **با نریشن** (ویس خود گوینده + Forced Alignment یا TTS). عمودی یا افقی. آموزشی، معرفی محصول، استوری.

## ظاهر در یک نگاه
- **کاراکتر سه‌بعدی خمیری** (عکس GPT، یک PNG برای هر ژست) که با کد به **نقطه‌های هافتون مشکی روی پایه‌ی سفید** تبدیل می‌شود، روی **پس‌زمینه‌ی رنگی تخت**: کرم، صورتی، زرد، پریوینکل، نعنایی، نارنجی. رنگ پس‌زمینه با هر جمله کات می‌خورد و فلش سفید ۴ فریمی دارد.
- **دهان با ویس باز و بسته می‌شود**: انرژی ویس فقط وقتی یک کلمه ادا می‌شود دهان را باز می‌کند، با کمی لرزش هجایی. نفس کشیدن و تکان سر هم روی شروع هر کلمه.
- **متن بالا، راست‌چین:** هر کلمه دقیقاً وقتی ادا می‌شود می‌نشیند. کلمه‌ی کلیدی روی بلوک رنگی تخت که از راست کشیده می‌شود. برچسب `// ۰۱ — …`.
- **کارت‌های UI** سفید با دورخط مشکی ۴px و **سایه‌ی سخت** (۹px). دکمه، پلیر، فرم، انتخابگر صدا با موج زنده.
- **امضاها:** سکه‌های صورتی هافتون با حرف N که می‌چرخند و شناورند · کلمه/عدد غول‌آسا **پشت کاراکتر** · آواتار گرد سخنگو در گوشه‌ی صحنه‌های UI.
- **افکت‌ها** (از pdoom): گرین فیلم، زوم ضربه‌ای، لرزش، ابراهی رنگی روی لحظه‌های کلیدی.

## کد — شروع سریع
```tsx
import { Character, Avatar, mouthAt, Say, Kicker, Card, Coin, Giant, Bg, Grain, Flash, punch, ca, shake, … } from "../styles/halftone-pop";
const CHAR: CharSet = { dir: "vNN/char", poses: { idea: { mouth: [0.5, 0.53], mw: 0.08 }, … } }; // or PLACEHOLDER
const talk = mouthAt(VOICE_ENV, WORDS, t);   // VOICE_ENV: node tools/audio-env.mjs voice.mp3 src/vNN/voice-env.json 30 60 0.5
```
1. ویس ← `eleven-align.mjs` ← `src/vNN/words.json`. پاکت لب‌خوانی: `audio-env.mjs … 0.5` (release تند).
2. عکس ژست‌ها با پرامپت‌های `videos/08-nfp-promo/image-prompts.md` (بلوک ثابت کاراکتر + یک خط ژست، **دهان بسته**، پس‌زمینه‌ی شفاف) ← `public/vNN/char/<pose>.png`.
3. برای هر ژست جای دهان را اندازه بگیر: `mouth: [x, y]` کسری از عرض/ارتفاع عکس و `mw` عرض دهان.
4. `examples/v08/Video.tsx` را کپی کن. هر صحنه `React.FC<{t, f, talk, nod}>` است (t = ثانیه‌ی کل، f = فریم محلی) و زمان‌ها از `T(جمله, "کلمه")` می‌آیند.

## قطعه‌ها (API)
| قطعه | امضا |
|---|---|
| `Character` | `set pose f x bottom h talk nod at flip tilt cell` — ورود فنری از پایین، نفس، دهان |
| `Avatar` | `set f x y d talk at bg` — سر گرد با دورخط و سایه‌ی سخت |
| `mouthAt(env, words, t)` | باز شدن دهان 0..1 |
| `HalftoneImg` / `useHalftone` | هر عکسی ← هافتون (`width cell ink paper gamma contrast`)، کش‌شده |
| `Say` | `words t x y w size marks={{i:{bg,color,big}}} br align` — متن سینک با ویس |
| `Kicker` `Giant` | برچسب `// ۰۱ — …` · کلمه/عدد غول‌آسا (پشت کاراکتر بگذار) |
| `Card` `Tiny` `Btn` `Pointer` `Stamp` | اتم‌های UI (دورخط + سایه‌ی سخت) |
| `Coin` | سکه‌ی هافتون چرخان `x y s f seed letter a color` |
| `Bulb` `Stopwatch` `Plane` `Gauge` `Tag` `Sparkle` | تصویرسازی‌های هافتون |
| `Wave` | موج صدای زنده از پاکت |
| `Logo` | لوگوی NFP (عوض کن) |
| افکت | `Bg` `Grain` `Flash` · `punch(f, hits)` `ca(f, hits)` `shake(f, hits)` |

## صدا
ویس **بدون ادیت**. موزیک ende.app `vol-11` با حجم ۰.۱۱ زیر ویس. افکت‌های Kenney روی کلیک، کارت، مهر، ضربه‌ی عدد و زنگ لوگو. `drop_001` خیلی آرام روی کات‌ها. loudnorm لازم نشد (میانگین −۱۷dB).

## نسخه‌ی ۲ (بعد از درس از ویدیوهای قبلی) — الگوی اصلی
- **پالت:** سفید + رنگ‌های کم‌رنگ (sky/lav/mint) + آبی پررنگ `#2f5bea` + مشکی. **صورتی ممنوع.** رنگ کارت‌ها: نارنجی، فیروزه‌ای، بنفش، زرد.
- **کاراکتر:** عکس GPT سه‌بعدی ← هافتون با `tone: 0.42` (سایه‌ی خاکستری زیر نقطه‌ها، حجم را نگه می‌دارد)، سلول ۶. **بزرگ** (h≈۱۲۰۰–۱۲۶۰) و پایین‌چپ، کمی بیرون از قاب. بین صحنه‌ها ثابت می‌ماند و فقط ژستش عوض می‌شود (`PoseTrack` + جهش کوچک).
- **بدون لب‌خوانی.** زنده بودن = ورود کشویی با overshoot، تاب و بالا‌پایین ملایم، تکان سر روی کلمه‌ها، و **حلقه‌ی صدا** دور آواتار (`voiceAt`).
- **ترنزیشن‌ها** (هر کدام یک بار): دایره‌ی رنگی از کلمه‌ی کلیدی (`circleIn`) · پوشش از پایین (`coverUp`) · زوم به داخل گوشی (`zoomOut`/`zoomIn`) · حرکت سریع افقی با موشن‌بلر جهت‌دار (`whipIn/Out` + `BlurDefs`) · کات به مشکی با ضربه · زوم‌اوت به کلاژ.
- **متن:** خط ریز `// …` + تیتر که هر کلمه از جعبه‌ی خودش بالا می‌آید. کلمه‌ی کلیدی رنگی با **خط زیر دست‌کشیده** (`accents: {i: {swash: true}}`). فونت کلمه‌ی کلیدی باید همان فونت متن بماند.
- **لایه‌بندی:** پس‌زمینه ← گرید نقطه‌ای ← کلاژ/کارت‌ها ← گوشی ← کاراکتر ← نشانگر. پنل سفید گرد روی رنگ کم‌رنگ برای صحنه‌های UI. تایمر تولید بالا-چپ که تا لحظه‌ی «آماده» می‌شمارد.
- **کلاژ مرور:** از فریم‌های خود ویدیو با `remotion still --scale=0.34` در `public/vNN/recap/` بساز (`RECAP_FRAMES`).
- **پایان:** حروف لوگو یکی‌یکی می‌افتند (`LogoDrop`)، کاراکتر `peek` از پشت لوگو بالا می‌آید (داخل ظرف `overflow:hidden` بالای لوگو)، و کارت‌های استایل مثل بادبزن باز می‌شوند.

## درس‌ها
- ⚠ **درس از ویدیوهای قبلی روی v1:** «رنگ‌ها (به‌خصوص صورتی) بد، سکانس‌ها ساده، سکه‌های صورتی بی‌جذابیت، پس‌زمینه‌ها خالی، لب‌خوانی غیرواقعی، پایان ضعیف». راه‌حل‌ها همان بخش نسخه‌ی ۲ است.
- ⚠ هم ژست‌های بزرگ و هم ترنزیشن‌ها را از **مرجع فریم‌به‌فریم (۵fps)** دربیاور، نه از کانتکت‌شیت ۱fps.
- ✓ هافتون کدی روی هر عکس (حتی SVG موقت) ظاهر یکدستی می‌دهد. سلول ۷px برای کاراکتر ۱۰۰۰px و ۵px برای آواتار.
- ✓ ویس گوینده + Forced Alignment + گیت دهان روی بازه‌ی کلمه‌ها = لب‌خوانی باورپذیر بدون ویسم.
- ⚠ جداکننده‌ی `·` کنار رقم فارسی شبیه «۰» دیده می‌شود. در برچسب‌ها `—` بگذار.
- ⚠ `-webkit-text-stroke` فقط برای رقم/لاتین؛ برای سایه‌ی عدد غول‌آسا یک کپی مشکیِ جابه‌جاشده پشتش بگذار.
- ⚠ جمله‌ی بلند (۱۳ کلمه) در عمودی: size ۸۴ و کارت‌ها پایین‌تر از y ۶۶۰.
