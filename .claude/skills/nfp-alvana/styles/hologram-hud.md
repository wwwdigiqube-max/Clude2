# Hologram HUD (هولوگرام کهربایی روی پروژکتور)
**وضعیت:** ✅ کد آماده در Remotion · `src/styles/hologram-hud/` · قالب `Style-HologramHUD` = خودِ فیلم مرجع (در Studio پخش می‌شود) · فریم‌های ثابت `Style-HologramHUD-Look`
**مرجع:** فیلم ۵۹ث عمودی «ساعت‌های GPS و اینشتین» · کانتکت‌شیت `styles/previews/hologram-hud.jpg`
**اسم‌های صدازدن:** «هولوگرام»، «HUD کهربایی»، «سبک GPS»، «سبک ویدیو ۲۲»
**مرجع ظاهر:** یک اکسپلینر انگلیسی با هولوگرام نارنجی روی پروژکتور. متن فارسی، صحنه‌ها و انیمیشن‌ها مال خودمان است.

## کی بزنیمش
اکسپلینر علمی یا فنی **عمودی ۴۵ تا ۶۰ ثانیه با نریشن**، با این مسیر: یک واقعیت عجیب ← چرا ← عددها ← آزمایش یا اثبات ← نتیجه. هر جمله یک شات و یک انیمیشن دارد.
مناسب علم، فضا، تکنولوژی، تاریخ اختراع‌ها و «چطور کار می‌کند».

## ظاهر
- **صحنه:** اتاق تاریک با شبکه‌ی نقطه‌ای که آرام بالا می‌رود. پایین قاب دیسک پروژکتور کهربایی است و پرتو نور تا هولوگرام بالا می‌رود.
- **هولوگرام‌ها:** رندرهای GPT Image روی **مشکی خالص** که با `screen` روی صحنه می‌نشینند.
  - از جرقه‌های همگرا و پشت خط اسکنِ بالارونده ساخته می‌شوند.
  - شناورند، نفس می‌کشند و کمی می‌چرخند. گاهی فلیکر و پارگی افقی دارند.
- **فقط یک خانواده‌ی رنگ:**
  - کهربایی `#ff9a3c`
  - سفیدِ داغ `#fff0c8` برای تأکید
  - قرمز `#ff5a48` فقط برای کُند، خاموش و خطا
  - آبی و تیل ممنوع است.
- **عددها:** رقم لاتین با فونت Chakra Petch، در HUD و در زیرنویس. برچسب فارسی با Vazir Code و زیرنویس با Vazirmatn Bold است.
- **قاب HUD:** خط وضعیت بالا با ساعتی که میکروثانیه‌هایش می‌شمارد، و ریل‌های تیک‌دار کناری.
- **زیرنویس:** تایپی و کلمه‌به‌کلمه، با مکان‌نمای بلوکی. کلمه‌ای که در حال گفته شدن است سفیدِ داغ می‌شود و کلیدواژه کهربایی روشن.
- **ریتم:** ترنزیشن هر کات فرق دارد: ویپ، زوم‌ثرو، افتادن، VHS، گلیچ و پول‌بک. روی کلیدواژه‌ها هم دوربین ضربه و لرزش دارد.

## شروع سریع (کد موتور را نخوان؛ API پایین هست)
1. **پوشه‌ی ویدیو:** `src/styles/hologram-hud/demo/` را به `src/v01/` کپی کن.
   - در فایل‌های `src/v01`، ایمپورت `../lib/` را به `../styles/hologram-hud/lib/` و `../../documentary/cues` را به `../styles/documentary/cues` عوض کن.
   - در `Root.tsx` سه کامپوزیشن بساز: `V01` با `audio` برای پیش‌نمایش، `V01-Silent` برای رندر، و `V01-Look` با `times`.
2. **متن:** `pipeline/script.json` را در `videos/01/` کپی کن و جمله‌ها را بنویس.
   - عدد: `{هفت|7}`. انگلیسی: `{GPS|جی‌پی‌اس}`. کلیدواژه: `*…*`. شکست زیرنویس: ` / `.
   - بعد بزن: `node tools/script-prep.mjs videos/01`
3. **صدا:** `pipeline/voices.json` را کنارش بگذار و این‌ها را به ترتیب بزن:
   - `node --env-file=.env tools/doc-voices.mjs videos/01`
   - `node tools/doc-build-vo.mjs videos/01 public/v01/vo.wav src/v01/vo.json --lead 0.2 --tail 0.4 --tempo 1.17`
   - `node tools/captions.mjs videos/01 src/v01/vo.json src/v01/captions.json`
4. **عکس‌ها:** پرامپت‌ها در `pipeline/image-prompts.md` هستند (پایه‌ی مشترک + شیء).
   - کاربر عکس‌ها را می‌سازد و در `public/v01/img/` می‌گذارد.
   - روی هر عکس شبکه بکش و جای قطعه‌ها را برای برچسب‌ها اندازه بگیر (`satPt` و `crPt` در `scenes.ts`).
5. **شات‌ها:**
   - در `scenes.ts` هر جمله یک تابع `(c, t)` است و زمان‌ها فقط از `Wd(خط، "کلمه")` می‌آیند.
   - شروع شات‌ها در `cues.ts` است (`SH`).
   - در `director.ts`، جدول `SHOTS` ترنزیشن هر کات را تعیین می‌کند و `KICKS` ضربه‌ی دوربین روی کلیدواژه‌ها را.
6. **فریم ثابت قبل از رندر:** لحظه‌های مهم را در `LOOK` بگذار و بزن `npx remotion render V01-Look out/look --sequence --image-format=jpeg`. بعد کانتکت‌شیت بگیر و اصلاح کن.
7. **صدا و میکس:**
   - پرامپت افکت‌ها در `pipeline/sfx.json` است. بزن `node --env-file=.env tools/eleven-sfx.mjs …`.
   - با `node tools/sfx-takes.mjs stats|level …` بهترین نسخه‌ها را انتخاب و هم‌سطح کن.
   - `pipeline/build-audio.mjs` را کپی کن و رویدادها را روی کلمه‌ها بگذار.
   - در آخر `node tools/doc-mix.mjs` را بزن.
8. **رندر:** `npx remotion render V01-Silent out/v.mp4` حدود ۳ دقیقه برای ۶۰ ثانیه طول می‌کشد. بعد صدا را بچسبان:
   `ffmpeg -i out/v.mp4 -i out/mix-norm.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -movflags +faststart videos/01/final.mp4`
   `-shortest` نزن.

## API (`lib/holo.ts`)
| قطعه | امضا | کار |
|---|---|---|
| `room` · `projector` · `beam` · `finish` · `frameHud` | `(c, t)` · `(c, t, power)` · `(c, t, yTop, wTop, a)` | اتاق، دیسک پروژکتور، پرتو با ذرات، گرین و وینیت، قاب HUD |
| `holo` | `(c, name, cx, cy, w, t, { reveal, alpha, glitch, seed, life, tint })` | هولوگرام از عکس. `reveal` همان خط اسکن است. `life` شناوری و چرخش است. `tint` قرمزش می‌کند، برای حالت خاموش |
| `sparks` | `(c, x, y, rx, ry, p, seed)` | جرقه‌هایی که هنگام ساخته‌شدن هولوگرام جمع می‌شوند (`p` از ۰ تا ۱) |
| `rings` | `(c, x, y, r, t, a, sy)` | حلقه‌های چرخان HUD. با `sy=0.2` پایه‌ی هولوگرام می‌شود |
| `brackets` · `focusBox` · `reticle` | جعبه یا نقطه + `p` | کادر گوشه‌ای، کادری که می‌پرد، و قفل هدف |
| `shock` · `burst` · `glowDot` · `chevrons` · `pinShape` | | حلقه‌ی ضربه، رگه‌های نور، درخشش، فلش‌های پشت‌سرهم، پین نقشه |
| `hud` · `hudW` · `typed` | `(c, s, x, y, { size, color, align, alpha, glow, weight })` | متن HUD. تکه‌های فارسی با Vazir Code و تکه‌های لاتین با Chakra Petch، چیده‌شده از راست به چپ |
| `numUnit` | `(c, "+45.8", "میکروثانیه در روز", x, y, size, { col, a, glow, below, s })` | عدد بزرگ لاتین با واحد فارسی |
| `odometer` | `(c, v, digits, x, y, size, { col, a, box })` | شمارنده‌ی مکانیکی که ارقامش می‌چرخند، رو به بالا یا پایین |
| `dial` | `(c, x, y, r, v, t, { label, max, col, a, slam, s })` | گیج دایره‌ای. `slam` ضربه روی عدد است |
| `Chart` · `chartAxes` · `chartLine` | `chartLine(c, ch, pts, p, col, { fill, dash, w })` | نمودار خطی با سر درخشان. خروجی آن نقطه‌ی سر نمودار است |
| `clockFace` | `(c, x, y, r, ang, t, { col, a, ghost, sx, back })` | ساعت با رد عقربه. `ghost` زمان درست است و گوه‌ی جلو یا عقب افتادن را نشان می‌دهد |
| `toggle` · `ruler` | | کلید روشن/خاموش، خط‌کش سال‌ها با نشانگر |
| `caption` | `(c, chunk, t)` | زیرنویس تایپی. جای آن `CAP` است (y=1290) |
| `num` · `grp` | `num(-7.2) → "−7.2"` · `grp(20200) → "20,200"` | عدد لاتین با علامت، و جداکننده‌ی هزارگان |

## درس‌ها
- ✗ **آبی و تیل کنار کهربایی** رد شد. فقط یک خانواده‌ی رنگ: کهربایی، سفید داغ و قرمز.
- ✗ **عدد فارسی** رد شد. همه‌ی عددها رقم لاتین با فونت انگلیسی (Chakra Petch)، حتی در زیرنویس.
- ⚠ **نسخه‌ی اول کم‌تحرک بود.** خواسته این بود: «جزئیات بیشتر، موشن جذاب‌تر، مسیر ویدیو انرژی داشته باشه، مخاطب رو با انیمیشن‌های مختلف سرگرم کن». در نسخه‌ی تأییدشده:
  - هر جمله انیمیشن خودش را دارد. چند نمونه: رادار و سه‌ضلعی‌یابی، شمارنده‌ی ارتفاع، تور فضا-زمان، برخورد دو عدد، نقشه‌ی شهر با پین فراری، ادومتر عقب‌گرد، پرتاب از پشت افق، کلید نسبیت، تقویم و قفل هدف.
  - ترنزیشن هر کات فرق دارد.
  - دوربین روی کلیدواژه‌ها ضربه می‌زند.
- ⚠ **«جی‌پی‌اس» با حروف فارسی بد تلفظ شد.** مخفف‌های انگلیسی را در متن TTS لاتین بنویس: `{GPS|جی‌پی‌اس}`.
- ⚠ **موزیک کمی بلند بود.** زیر نریشن حدود ‎-31 LUFS بگذار (`musicKeys` ≈ 0.16).
- **دام فونت:** اگر در متن فارسی Chakra Petch اول فونت‌استک بیاید، فاصله‌ی کلمه‌ها از آن گرفته می‌شود و کلمه‌ها به هم می‌چسبند. `hud` متن را تکه‌تکه با فونت خود هر تکه می‌چیند.
- **دام رنگ:** قرمز کردن با `multiply` روی لایه‌ی شفاف، دور عکس کادر قرمز می‌سازد. از `filter: hue-rotate` استفاده کن (`tint`).
- **دام bidi:** علامت + یا − قبل از عدد، داخل جمله‌ی فارسی جابه‌جا می‌شود. عدد علامت‌دار را جدا بکش (`numUnit`).
- **دام افکت:** هر دو نسخه‌ی افکت «toggle» از ElevenLabs تقریباً بی‌صدا بودند. همیشه `sfx-takes.mjs stats` را بزن. جای آن سوییچ Kenney گذاشته شد.
- **فریم اول:** فریم اول تاریک نیست، چون هولوگرام شروع از ۷۰٪ ساخته‌شده شروع می‌شود. کلمه‌ی اول هم زیر ۰.۳ ثانیه می‌آید.
