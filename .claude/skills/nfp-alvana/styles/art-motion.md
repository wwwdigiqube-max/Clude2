# Art Motion — بسته‌ی سبک‌های نسخه‌ی ۲ (۴۵ سبک)
**وضعیت:** ✅ کد آماده (Canvas 2D داخل Remotion، بدون کارت گرافیک). `src/styles/art-motion/` + موتور در `public/styles/art-motion/engine/`.
- **۳۶ سبک «نقاشی متحرک»** (شماره‌ی ۱۹ تا ۵۳ و ۶۲): از غار و مصر تا ون‌گوگ، پاپ‌آرت، پیکسل و شینکای. هر کدام یک صحنه‌ی زنده‌ی ۱۹۲۰×۱۰۸۰ و یک **ترنزیشن امضا** دارد.
- **۹ «زبان توضیحی»** (شماره‌ی ۵۴ تا ۶۱ و ۶۳): کیهان تخت، کلاژ خبری، تخته‌سفید، قصه‌گو، تایپوگرافی ضربه‌ای، ریاضی متحرک، کی‌نوت، چارت مالی، خوشنویسی. کل ویدیو یک spec JSON است.
- **دو سبک ویژه‌ی NFP** که جای دیگری نیست: `art-persian` (نگارگری ایرانی با ترنزیشن گره) و `ex-calligraphy` (نستعلیق روی صفحه‌ی تذهیب‌شده).

**کانتکت‌شیت:** `styles/previews/art-motion.jpg`. **نمونه‌ی هر سبک** در Studio، پوشه‌ی `Art-Motion-v2`: `Art-<Style>` (موزه‌ی متحرک)، `Explainer-<Style>`، `Art-Story`، `Art-Poem`، `Art-Journey`.
**اسم‌های صدازدن:** اسم فارسی یا انگلیسی هر سبک («با سبک ون‌گوگ»، «مثل کورتزگزاگت»، «تخته‌سفید»، «نگارگری»)، «سبک‌های نسخه‌ی ۲»، «نقاشی متحرک»، «آرت موشن».
**منبع:** موتور [huashu-art-motion](https://github.com/alchaincyf/huashu-art-motion) (MIT) + لایه‌ی فارسی NFP: راست‌به‌چپ، نستعلیق و نسخ، رقم لاتین، و دو سبک ویژه.

## ۱. قانون طلایی: ویدیو = داده، نه کد
- در این بسته **کد صحنه نمی‌نویسی.** یک آرایه‌ی `beats` (قصه)، یک `spec` (زبان توضیحی) یا چند مصراع (شعر) می‌نویسی. موتور بقیه را می‌کشد.
- **هزینه‌ی یک ویدیو:** همین کارت (حدود ۷k توکن) + یک فایل starter (حدود ۰.۶k). نه بیشتر.
- **هرگز نخوان:**
  - `public/styles/art-motion/engine/**` (حدود ۱۵ هزار خط کد موتور، کامنت‌ها چینی)
  - `catalog.ts` و `palettes.json` (همه‌چیزشان در جدول‌های همین کارت هست)
  - `film.ts`، `clip.ts`، `runtime.ts`، `ArtCanvas.tsx`
- اگر چیزی را این کارت نگفته، اول `demo/specs.ts` یا `demo/Samples.tsx` را ببین (نمونه‌های واقعی)، نه موتور را.

## ۳. ساخت یک ویدیو
1. سبک یا سبک‌ها را از جدول بخش ۴ (یا زبان را از بخش ۵) انتخاب کن. اگر کاربر نگفته، دو سه پیشنهاد با یک خط دلیل بده.
2. `cp src/art-starter/StoryVideo.tsx src/v01/Video.tsx` (یا `ExplainerVideo` / `PoemVideo`). **فقط بلوک داده را عوض کن.**
3. در `src/Root.tsx`: `import { V01 } from "./v01/Video";` و `<V01 />` داخل RemotionRoot. برای ویدیوی بعدی اسم‌ها را V02 کن.
4. فریم‌ها قبل از رندر: `npx remotion render V01-Look out/look --sequence --image-format=jpeg --scale=0.5 --log=error` و بعد کانتکت‌شیت (`SKILL.md` بخش ۹).
5. **نریشن (اختیاری):** خط تولید `AUDIO.md` (`script-prep` ← `doc-voices` ← `doc-build-vo` ← `src/v01/vo.json`).
   - در Story: `vo` و `audio` بده. beat شماره‌ی i = خط i در lines.json. هر کلمه‌ی زیرنویس **همان لحظه‌ای که گفته می‌شود** ظاهر می‌شود.
   - در Explainer: `at` هر cue = زمان کلمه‌ی مربوطش در vo.json (تابع `Wd` در starter).
   - موزیک و افکت: مثل بقیه‌ی کیت (`doc-mix`).
6. رندر: `npx remotion render V01 out/v01.mp4 --concurrency=4 --log=error`. دوبعدی است و کارت گرافیک نمی‌خواهد. ستون ms هزینه‌ی هر فریم است؛ سبک‌های بالای ۱۰۰ms (ون‌گوگ، مونه، سورا، مونک، خیمه‌شب‌بازی) کندترند.

**Story props:**
```ts
{ beats: [{ style: "art-…", text: "یک جمله", key?: "کلمه‌ی رنگی", focus?: 0..1, at?: ثانیه }],
  title?, sub?, layout?: "vertical" | "landscape", each?: 3, vo?, audio?: "v01/mix.wav", accent?: "#FF9A66", tail?: 0.6 }
```
- `focus` = مرکز قاب عمودی روی عرض نقاشی. پیش‌فرض هر سبک جای سوژه‌اش است (معمولاً آدمِ پشت میز). اگر چیز دیگری مهم است (پنجره‌ی شب پرستاره، پل مونه)، `focus` بده.
- **Poem:** `{ style, lines: [مصراع…], poet?, at?: [ثانیه‌ی هر مصراع], pan?: [از, تا], duration? }`.
- **Journey:** `{ stops: [{ style, dur?, label?, era? }], layout, title?, sub?, each?: 1.2 }`. مدت را `journeyLength(stops, each)` می‌دهد.

## ۵. ۹ زبان توضیحی (spec)
```ts
{ grammar, duration, fps: 30, width: 1080, height: 1920, safe: { top: 120, bottom: 330 }, theme?, data?,
  cues: [{ at, kind, text?, sub?, data?, image?, frames? }] }   // at = ثانیه‌ای که آن چیز باید دیده شود
```
- **theme** (پالت کل فیلم، ۶ رنگ bg/surface/ink/sub/accent/accent2): `paper` کاغذی، `poster` زرد پوستری، `ink` جوهر تیره، `navy` سرمه‌ای، `bauhaus`، `snow` برفی، `wood` چوب گرم، `chalk` تخته‌سیاه. ننوشتی = پیش‌فرض خود زبان.
- `safe`: محتوا فقط بین top و H−bottom می‌نشیند؛ ۳۳۰ پیکسل پایین ریلز برای رابط اینستاگرام خالی می‌ماند.
- عکس و فریم از `public/` (مسیر بدون `/` اول).

## ۶. فارسی و ظاهر
- لایه‌ی `engine/lib/fa.js` هر متن فارسی را راست‌به‌چپ می‌کشد و فونت‌های لاتین موتور را با Vazirmatn، نسخ و نستعلیق جفت می‌کند. تو فقط فارسی بنویس. حروف هرگز جدا جدا متحرک نمی‌شوند.
- **عدد = رقم لاتین** («63 سبک»، «3.5 برابر»). کاتالوگ هم رقم فارسی را خودکار لاتین می‌کند.
- برچسب‌های چینیِ داخل تابلوهای اصلی حذف یا فارسی شده‌اند (`ART.labels`: `"off"` پیش‌فرض قالب‌ها، `"fa"` برچسب فارسی، `"source"` اصل).
- نگارگری: بیت روی کتیبه = `window.PERSIAN_VERSE` (پیش‌فرض سعدی). نقاشی غار: `window.CAVE_TITLE`.
- **اکسنت** قالب‌ها نارنجی `#FF9A66` است (`accent` در Story).
- زیرنویس Story در y حدود ۱۲۵۰ تا ۱۵۰۰ است، بالای رابط اینستاگرام. هر beat یک جمله‌ی کوتاه (زیر حدود ۱۲ کلمه) و حداقل ۲.۵ ثانیه.

## ۸. درس‌ها
- قاب عمودی فقط ۳۲٪ عرض نقاشی را نشان می‌دهد. بدون `focus` سوژه بیرون می‌افتد (نسخه‌ی اول: از هاپر فقط دیوار دیده می‌شد).
- ترنزیشن روی مرز دو جمله وسط‌چین است: کمی قبل از جمله‌ی تازه شروع می‌شود تا کلمه‌ی اول روی تصویر تازه بیاید.
- رنگ پیش‌فرض بعضی زبان‌ها (لکه‌های نور کی‌نوت) سبزآبی دارد. برای پالت برند `theme` بده.
