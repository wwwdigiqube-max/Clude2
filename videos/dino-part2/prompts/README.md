# قسمت ۲ · پرامپت‌های قاب‌ها (Flow Agent)

- ۷ دسته، ۵۹ عکس (۵۰ تازه + ۹ ویرایش). هر فایل یک پرامپت بلند است برای حالت Agent.
- پیوست‌های هر دسته بالای فایلش نوشته شده. اسم‌هایی مثل HERO و TUNNEL داخل پرامپت به همان پیوست‌ها اشاره می‌کنند.
- Agent اسم هر عکس را شماره‌ی قاب می‌گذارد (`p2-004`). عکس‌ها را با همین اسم در درایو بگذار.
- ساخته‌شده با `build_prompts.py` از روی `../shotlist/shotlist.md`. ستون وضعیت (زخم، پیپ، نور) داخل هر قاب نوشته شده.
- دو قاب دیگر عکس تازه نمی‌خواهند: #43 = P7 (عکس و «MISSING» در تدوین)، #156 = P8.
